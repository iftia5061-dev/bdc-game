# 🪙 BDC Coin - Telegram Mini App (Crypto Mining)

**BDC Coin** is a next-generation Telegram Mini App (TMA) designed for a seamless crypto mining experience. Built for the Telegram ecosystem, it allows users to mine, earn, and manage BDC Coins directly within their chat app.

## 🚀 Features
- **Tap-to-Earn:** Simple and addictive mining mechanic.
- **Wallet Integration:** Securely connect and manage crypto assets.
- **Referral System:** Earn bonuses by inviting friends to the BDC ecosystem.
- **Real-time Stats:** Track your mining progress and global rank.
- **Sleek UI/UX:** High-performance interface optimized for mobile devices.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (React/Vue context)
- **Backend:** Node.js / Python (FastAPI/Flask)
- **Database:** MongoDB / PostgreSQL
- **Platform:** Telegram Bot API & Telegram Web Apps (TWA)

## 📖 How to Use
1. Search for `@BDC_Coin_Bot` on Telegram.
2. Launch the Mini App.
3. Start tapping to mine BDC Coins!
4. Complete tasks and invite friends to multiply your earnings.
